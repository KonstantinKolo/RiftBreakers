# RiftBreakers

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)  
[![Godot Version](https://img.shields.io/badge/Godot-4.5-blue.svg)](https://godotengine.org/)

**RiftBreakers** is an open-source **3D action game** built with the **Godot Engine**.  
Developed as part of a diploma project, it explores combat mechanics, character movement, and enemy AI behaviors.  

This project is perfect for students, hobbyists, and Godot enthusiasts who want to study or contribute to a clean and modular 3D game codebase.

---

## 🎮 Features
- Smooth and responsive 3D player movement  
- Basic melee combat system  
- Simple enemy AI (patrol + chase)  
- Hitbox and hurtbox interactions  
- Modular scenes with clean, well-structured GDScript  

---

## 🕹️ Controls
| Action | Key |
|--------|-----|
| Move | W/A/S/D |
| Jump | Space |
| Attack | Left Click |
| Switch Camera / Zoom | Right Click |
| Sprint | Shift |
| Look / Camera | Mouse |

## 🚀 How to Play
1. Download the latest `.zip` for your OS from the [Releases](https://github.com/KonstantinKolo/RiftBreakers/releases) page.  
2. Unzip and run the executable.  
3. Enjoy the game!
